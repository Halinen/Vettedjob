# Candidate profile for fit scoring

This profile is intentionally focused on current target roles. It is used only by
the optional fit-scoring layer; the legitimacy filter does not read it.

## Target directions

1. Systems-oriented MLE / AI Software Engineer roles combining:
   - C++ systems programming
   - machine learning / AI infrastructure
   - performance optimization
   - inference/runtime/compiler/GPU/CUDA/vectorization work
   - low-latency or high-throughput production systems

2. Quant developer / quant research internship roles combining:
   - C++ or Python for trading/research systems
   - statistics, machine learning, numerical methods, or optimization
   - performance-sensitive engineering
   - data pipelines, backtesting, simulation, or market data systems

## Strong fit signals

- C++ is a core requirement, especially modern C++ or performance-critical code.
- The role mentions ML systems, AI infrastructure, inference optimization,
  compilers, runtimes, CUDA/GPU, model serving, distributed systems, latency,
  throughput, profiling, or memory/performance optimization.
- The role is an AI Software Engineer, ML Systems Engineer, MLE Infrastructure
  Engineer, Inference Engineer, Compiler Engineer, Performance Engineer, or
  similar systems-heavy ML/AI role.
- For quant roles, prioritize internships or early-career roles in quant dev,
  quant research, trading systems, systematic trading, market data, backtesting,
  pricing, risk, or numerical computing.

## Weak fit / low-score signals

- Pure frontend, mobile, product analytics, IT support, sales engineering, data
  entry, BI dashboarding, marketing analytics, or generic business analyst roles.
- Pure data science roles that mainly involve dashboards, stakeholder reporting,
  SQL-only analysis, or no systems/performance component.
- Senior/staff/principal/manager quant roles unless explicitly open to interns or
  early-career candidates.
- Finance-adjacent sales, insurance, financial advisor, forex/crypto promoter, or
  commission-only roles.

## Location and work mode

- Base location should be Toronto / Greater Toronto Area. On-site, hybrid, or
  remote roles are acceptable only if they are based in or open to Toronto/GTA.
- Do not prioritize US-only or Canada-wide roles that are not Toronto/GTA based.
- For internships, prefer roles that are open to students/new grads or explicitly
  say intern/co-op.
